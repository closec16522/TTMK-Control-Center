## 📌 ภาพรวมระบบ (System Overview)
ระบบแจ้งซ่อมและบันทึกประวัติการซ่อมบำรุงรถบรรทุก 6 ล้อ (ทั้งเครื่องยนต์ดีเซลและรถไฟฟ้า EV 100%) ถูกออกแบบมาเพื่อรองรับ:
1. **การบันทึกอาการเสีย & ความเร่งด่วน:** ระบุระบบที่ชำรุด (เบรก, เครื่องยนต์, แบตเตอรี่ EV, ยาง ฯลฯ) พร้อมรายละเอียด
2. **ระบบเพิ่มรายการอะไหล่หลายรายการต่อ 1 ใบแจ้งซ่อม (+ เพิ่มรายการ):** บันทึกอะไหล่ ค่าแรง หมวดหมู่ จำนวน หน่วย ราคาต่อหน่วย และคำนวณยอดเงินรวมอัตโนมัติ (พร้อมตัวเลือกภาษีมูลค่าเพิ่ม VAT 7%)
3. **การแนบหลักฐานภาพถ่าย & บิลค่าซ่อม (4 ภาพ):**
   - 🧾 รูปบิลค่าซ่อม / ใบเสร็จรับเงิน / ใบกำกับภาษี
   - 📸 รูปจุดที่ชำรุดก่อนซ่อม
   - 📸 รูปอะไหล่ใหม่ / ขณะกำลังซ่อม
   - 📸 รูปงานหลังซ่อมเสร็จ
4. **การส่งออกเอกสารใบแจ้งซ่อมมาตรฐาน A4 (Printable Work Order):** ออกแบบฟอร์ม A4 สวยงาม พร้อมช่องลงนาม 3 ฝ่าย (พขร. ผู้แจ้งซ่อม, ช่างผู้ซ่อม, TSM/ผู้จัดการอนุมัติ) สั่งพิมพ์ตรงหรือบันทึกเป็น PDF ได้ทันที
5. **ระบบจดจำพนักงานขับรถอัตโนมัติ:** ซิงก์กับมาตรฐานเดียวกันของระบบตรวจแอลกอฮอล์และตรวจสภาพรถ (`TTMK_SAVED_DRIVER_EMAIL`)

## 🚀 วิธีการติดตั้ง Google Apps Script (Backend Setup)
1. เปิด Google Sheet ID: `1JM-i8_nrGR7-VDEY82QZ5l5JMJTIBOIsuqOSQSrcD3Y`
2. ไปที่เมนู **ส่วนขยาย (Extensions)** &gt; **Apps Script**
3. คัดลอกโค้ดจากไฟล์ `C:\TTMK\maintenance\Code.gs` ไปวางในโปรเจกต์ Apps Script
4. กดบันทึก (Save)
5. กดปุ่ม **ทำให้ใช้งานได้ (Deploy)** &gt; **การทำให้ใช้งานได้รายการใหม่ (New deployment)**
   - เลือกประเภท: **เว็บแอป (Web app)**
   - คำอธิบาย: `TTMK Maintenance API v1`
   - ดำเนินการในฐานะ: **ฉัน (Me / เจ้าของชีต)**
   - ผู้ที่มีสิทธิ์เข้าถึง: **ทุกคน (Anyone)**
6. กดปุ่ม **ทำให้ใช้งานได้ (Deploy)** และคัดลอก **URL เว็บแอป (Web App URL)**
7. นำ Web App URL ไปใส่ใน `DEFAULT_GAS_URL` ของ `c:\TTMK\maintenance\app.js`
