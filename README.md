# 🚚 TTMK Control Center Dashboard

ระบบบริหารจัดการและควบคุมระบบขนส่ง TTMK Control Center Dashboard พัฒนาด้วย HTML, Tailwind CSS, Font Awesome, Chart.js และ SweetAlert2 พร้อมระบบเชื่อมต่อฐานข้อมูล Google Sheets และ Google Drive แบบ Real-time

---

## 🌟 ฟีเจอร์หลัก (Features)
- 📊 **ภาพรวมระบบขนส่ง (Overview)**: KPI คันวิ่งงาน, แจ้งเตือนฉุกเฉิน, รถถึงกำหนด PM, คะแนนความปลอดภัย, กราฟสถิติพฤติกรรมขับขี่ AI และ Live GPS Tracking
- 🔔 **SCG Alerts**: ระบบตอบกลับและจัดการการแจ้งเตือนจากส่วนกลาง (Fatigue, Overspeed, Route Dev.)
- 💵 **ระบบตั้งเบิก / รายได้วิ่งรถ (Billing)**: ดึงข้อมูล Feed รอบวิ่งรถและราคาตามโซน พร้อมฟังก์ชันสั่งพิมพ์ใบเบิกเงิน
- 📋 **ตรวจสอบความปลอดภัย (LIFF)**: ฟอร์มสุ่มตรวจความปลอดภัย (คาดเข็มขัด / ใช้โทรศัพท์)
- 🛠️ **จัดการรถ & ซ่อมบำรุง (Maintenance)**:
  - ระบุสถานที่ซ่อม / ศูนย์บริการ
  - รายการงานซ่อมบำรุงแบบ 3 ช่องเรียงแถว (ประเภทงาน, รายละเอียด, ราคา) พร้อมคำนวณราคารวมอัตโนมัติ
  - **แนบรูปถ่ายใบเสร็จ** (บังคับถ่ายรูปจากกล้องเท่านั้น ห้าม Upload)
  - **แนบรูปถ่ายจุดซ่อม/อะไหล่** (บังคับถ่ายรูปจากกล้องเท่านั้น ห้าม Upload)
- 👥 **ทีมงาน & เบิกจ่าย (Employees)**: ฟอร์มเบิกค่าน้ำมัน, เบี้ยเลี้ยง, ทางด่วน, และค่าซ่อมรายทาง
- 🌙 **ระบบสลับโหมดมืด/โหมดสว่าง (Dark / Light Mode)**: รองรับการสลับธีมพร้อมบันทึกค่าลง LocalStorage
